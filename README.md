# CCA Informatics & Competitive Programming

FIS International School, Singapore  
**Co-founded by:** FlamingBlade & jager59  
**Schedule:** Every Thursday & Friday, 4:00 PM – 6:00 PM  
**Starting:** July 23, 2025  
**Language:** C++

---

## Overview

This CCA is designed for **complete beginners** with no prior programming experience, while also supporting students who already have some foundation in C++. We use a **two-track system**:

| Track | Audience | Mode |
|-------|----------|------|
| **Foundation** | ~80% — Zero prior experience | Instructor-led lessons + guided practice |
| **Acceleration** | ~20% — Some C++ background | Self-directed study guides + Socratic mentoring |

## Weekly Flow

```
4:00 – 4:10   Joint warm-up problem (both tracks)
4:10 – 4:15   Acceleration Track: briefing & goals
4:15 – 5:30   Foundation Track: lesson + practice
              Acceleration Track: self-study via study guide + mentoring
5:30 – 5:45   Code review (projection, whole group)
5:45 – 6:00   Joint wrap-up + next week preview
```

---

## Study Guide Format

Each study guide includes:
- 📖 Pre-reading
- 📝 Required problems (with hints in collapsible blocks)
- 🚀 Challenge problems
- ✅ Self-check checklist
- ⚠️ Common pitfalls

Rendered natively on GitHub with `<details>` collapsible sections — just like Codeforces editorials.
