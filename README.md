## 🗺️ Learning Tracks

### Foundation Track (80% — complete beginners)
Covers C++ from zero: variables → loops → arrays → functions → basic algorithms.

### Acceleration Track (20% — students with prior experience)
Self-paced problem sets with Socratic mentoring. Focuses on STL, algorithms, and problem-solving strategies.
